2. Nose
3. Mouth / lips
4. Overall facial structure

6. Eyes / brow

## Ratings equations — controlling A1 method
A1 sets the ratings; donor/system values do not define the player.

- Normalize older EA/Madden rating scales to the A1 0–99 scale before averaging.
- For each Madden year, use the highest/final usable same-position-family representative version; use a lower same-family version only as a labeled fallback when the higher version’s attributes cannot be recovered.
- TRUE(attribute) = rounded arithmetic mean of every usable annual same-position-family value for that attribute.
- Missing attributes are excluded from the denominator; missing never equals zero.
- If an older Madden appearance lacks a later attribute, use a comparable later EA/Madden appearance with a complete attribute set as the project’s approved fill/reference method rather than inserting zero.
- OOP: calculate each legitimate out-of-position family separately.
- If the same OOP family appears more than once, average those OOP appearances first to produce the OOP-family value.
- TWO: after TRUE and OOP family values are separately calculated, average the family values equally. If more than two legitimate position families exist, average the family averages equally rather than weighting by number of cards.
- Preserve the overall-rating evidence separately from the attribute-by-attribute TRUE calculations.
- Historical evidence is a sanity check/correction; one season or one card is not automatically the whole player.
